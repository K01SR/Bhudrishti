# Pinned to a range that can actually reach a patched starlette.
#
# The previous `fastapi>=0.111.0,<0.115.0` resolved to fastapi 0.114.2, which
# requires starlette<0.39. That made starlette 0.38.6 the only installable
# version, and it carries 7 distinct known advisories (14 records):
# PYSEC-2026-1943, -1941, -161, -2281, -2280, -249, -248. Fixed in 0.40.0,
# 0.47.2, 1.0.1, 1.1.0, 1.3.0 and 1.3.1 respectively. The upper bound on fastapi
# was the whole reason none of them were reachable -- no starlette >= 0.40 could
# ever be installed.
#
# This was invisible in CI because the pip-audit step ran with
# `continue-on-error: true`, so 14 findings had been reported and ignored.
# starlette is the ASGI layer underneath FastAPI, so this was the most
# substantive finding in the repository, not a dev-only transitive.
#
# starlette is now also pinned explicitly rather than left to fastapi's
# resolution, so a future fastapi range cannot silently walk it back into a
# vulnerable version without a visible diff.
