## 1. Sovereign Design Tokens
The user interface implements an executive, government-grade dark/neutral visual language:
* **Backgrounds:** Canvas `#0a0a0f`, Surface `#12121a`, Elevated Surface `#1a1a24`.
* **Accent:** Primary Cyan `#06b6d4`, Secondary Indigo `#6366f1`, Gold `#f59e0b`.
* **Status Badges:** Approved `#10b981`, Under Review `#f59e0b`, Encroached `#ef4444`.
* **Component Registry:** `StatCard`, `Badge`, `Card`, `Tabs`, `EmptyState`, `ErrorState`, and `GlobalSearch` Command Palette.
